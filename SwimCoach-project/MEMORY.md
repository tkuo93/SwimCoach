# SwimCoach Memory

This file stores learnings and insights from past workout feedback to improve future workout generation.

## Format

Each entry follows this structure:
```
### [Date] — [Profile Name]
- **Workout Type**: [type]
- **Rating**: [1-5]
- **Difficulty**: [too-easy/easy/just-right/hard/too-hard]
- **Enjoyment**: [did-not-enjoy/neutral/enjoyed/loved]
- **Comments**: [user comments]
- **Learning**: [insight for future generation]
```
